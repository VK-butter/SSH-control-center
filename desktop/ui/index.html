เลือก session ของ

เครื่องนี้มีผู้ใช้ Owner login อยู่หลาย session เลือก session ที่จะเปิด Shell

เปิดสองทางกับ

ให้ สั่งเครื่องลูกของเครื่องนี้ได้ เหมือนที่เครื่องนี้สั่งเครื่องลูกของเครื่องนั้นอยู่แล้ว

Windows จะขอสิทธิ์ admin หนึ่งครั้งเพื่อติดตั้งบนเครื่องนี้:

  • OpenSSH Server (ถ้ายังไม่มี)
  • บัญชี sshcc-bridge ที่รับเฉพาะคำสั่งของ Control Center
  • กุญแจของ ใน authorized_keys และบทบาท Target ของ service
รายละเอียดเพิ่มเติม

ระบบลงทะเบียนเครื่องนี้เป็น Target ของเครื่องนั้นด้วยขั้นตอนจับคู่ปกติ · Firewall คงตามเดิม เครื่องนั้นต้องเข้าพอร์ต 22 ของเครื่องนี้ได้ · ปิดภายหลังได้ด้วย “ปิดการ merge” หรือถอนสิทธิ์ Master
