### Issue tracker

Issues live as local markdown files under `.scratch/` (git-ignored, never pushed to the public fork). See `docs/agents/issue-tracker.md`.

The five default labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), written as a `Status:` line. See `docs/agents/triage-labels.md`.
